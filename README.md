# Library System

## Description

Simple Library Information System

## Requirements

- PHP
- Composer
- Laravel

## Installation

1. Clone repository ini
2. Jalankan `composer install`
3. Copy `.env.example` menjadi `.env`
4. Jalankan `php artisan key:generate`
5. Jalankan `php artisan serve`
